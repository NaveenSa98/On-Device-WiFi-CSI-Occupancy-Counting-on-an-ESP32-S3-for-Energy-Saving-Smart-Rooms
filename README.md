# On-Device-WiFi-CSI-Occupancy-Counting-on-an-ESP32-S3-for-Energy-Saving-Smart-Rooms
SmartRoomSense is a low-cost, camera-free sensor that counts the people in a room (0, 1, 2, 3+) from WiFi Channel State Information (CSI). A quantized neural network runs on the ESP32-S3 microcontroller itself, and the count drives lights and fans through a dashboard and simple automation rules
